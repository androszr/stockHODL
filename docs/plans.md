# Plans

Implementation plans written by `/ship`. One file per change, named
`<YYYY-MM-DD>-<slug>.md`, under `plans/` at the repository root.

`plans/` is git-ignored local working notes: the plans stay on the author's
disk and are never published. Dated `plans/…` citations in code comments and
in `docs/context.md` are the decision record's pointers and may not resolve
in a fresh clone.
