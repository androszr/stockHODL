# Contributing to StockHODL

Thanks for taking a look. This is a small personal project — issues and pull
requests are both welcome, on GitHub, but it is built for one person's
portfolio and it will stay that way: a change that adds a second user, a
website, or a second market-data vendor is a fork, not a pull request.

## Development setup

You need Node 24 with pnpm 11 for the server, and Xcode 26 (Swift 6.2) for
the iPhone app. [docs/setup.md](docs/setup.md) walks through the accounts
(Neon, Massive, Vercel, Apple) from a fresh clone.

```bash
pnpm install
cp .env.example .env      # then fill it in
pnpm db:migrate
pnpm dev
```

Open `ios/StockHODL.xcodeproj` in Xcode for the app. The Debug build on the
simulator talks to `http://localhost:3000`.

## The gates

Every change passes these before it is handed back, in this order — the fast
ones fail first:

```bash
pnpm lint
pnpm typecheck
pnpm test
pnpm build
```

And, when anything under `ios/` changed:

```bash
xcodebuild build -project ios/StockHODL.xcodeproj -scheme StockHODL \
  -destination 'generic/platform=iOS Simulator' -quiet
xcodebuild test -project ios/StockHODL.xcodeproj -scheme StockHODL \
  -destination 'platform=iOS Simulator,name=<a device you have>' -quiet
python3 scripts/check-entitlements.py
python3 scripts/check-privacy-strings.py
```

The canonical list is the Identity table in [docs/context.md](docs/context.md).
CI runs the four web gates on every push to `main` and every pull request
that touches more than `ios/` (`ci.yml`), and the iOS ones on every push to
`main` and every pull request (`ios.yml`).

If you change a contract under `src/lib/api/contracts/` or a token in
`src/styles/tokens.css`, run `pnpm ios:gen` and commit the regenerated Swift —
CI fails on any drift between the two.

## The rules that matter

[docs/context.md](docs/context.md) is the ground truth. The ones a review will
stop on:

- **No float money math.** Amounts are decimal strings through
  `src/lib/money.ts` and `Money.swift`; `parseFloat`, `Number()` or `Double(`
  on a price, quantity, fee or FX rate is a bug.
- **Market data is server-mediated.** The phone never calls a vendor.
- **Two allowlist gates stay intact** in `src/lib/auth.ts`.
- **Migrations are additive**, and persisted shapes decode tolerantly.

## How a change is made here

Most changes in the history were made with coding agents, through a `/ship`
skill: it interviews, writes a plan, and a card on a Kanban board (Dark Army)
runs that plan to completion with a blind verifier and a bug scan behind it.
You do not need any of that to contribute — a plain pull request with passing
gates is fine.

- **`plans/` is local working notes.** It is git-ignored: the plans stay on the
  author's disk and are never published. Dated `plans/…` citations in comments
  are the decision record's pointers ([docs/plans.md](docs/plans.md)).
- **Some files are regenerated by the Dark Army agent pack.** The regions
  between `BEGIN`/`END DARK ARMY PACK` markers in `AGENTS.md`, `CLAUDE.md`,
  `docs/context.md` and `.claude/review.md`, the whole of `GEMINI.md`, and
  the `gitnexus:start` blocks are overwritten on the next resync. Edit below
  the markers, never inside them.
